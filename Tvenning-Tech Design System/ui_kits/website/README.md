# Tvenning-Tech Website UI Kit

A click-through prototype of the Tvenning-Tech marketing website.

## Pages

| Page | How to access |
|------|--------------|
| Home | Default / click logo |
| Work | Click "Work" in nav or "View my work" hero CTA |
| Services | Click "Services" in nav |
| About | Click "About" in nav |
| Contact | Click "Contact" or "Get in touch" |

## Components

| File | Description |
|------|-------------|
| `Header.jsx` | Sticky nav — transparent on load, frosted glass on scroll |
| `Hero.jsx` | Full-viewport blue hero with Selbu strip accents and dual CTAs |
| `Services.jsx` | Services card grid + tabular work listing |
| `Footer.jsx` | Dark contact CTA band + Selbu divider strip + blue footer |
| `index.html` | Main app shell wiring all components together |

## Design tokens used
All tokens from `colors_and_type.css` at the project root.
Fonts loaded from Google Fonts: Syne, DM Sans, JetBrains Mono.
Assets referenced from `../../assets/`.
